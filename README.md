# Hotel Paulette

Sitio web estático para el hotel, separado en HTML, CSS y JavaScript.

## Estructura

```text
.
├── assets/
│   ├── css/
│   │   └── styles.css
│   ├── js/
│   │   └── app.js
│   └── README.md
└── index.html
```

## Ejecutar

Abre la carpeta en Visual Studio Code y sirve el proyecto con una extensión de servidor estático, por ejemplo **Live Server**. Se recomienda usar un servidor local porque el JavaScript utiliza módulos ES y Firebase desde CDN.

## Publicar

El proyecto puede publicarse como sitio estático, por ejemplo con GitHub Pages. Las dependencias visuales y Firebase se descargan desde CDN; se necesita conexión a Internet para cargarlas.
