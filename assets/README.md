# Recursos del sitio

- `css/styles.css`: estilos específicos de la página principal.
- `js/app.js`: navegación y comportamiento de la página; importa los catálogos y utilidades de `../../src/index.js`.

La librería reutilizable del proyecto está en `../src/`:

- `src/index.js`: API pública del paquete `tap-booking-ui-lib`.
- `src/style.css`: tokens de tema y estilos del widget de reservas.

Tailwind CSS, Google Fonts, Font Awesome y Firebase se cargan desde sus CDN.
